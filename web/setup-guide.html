ADR Governance Studio Setup Guide

This guide provides complete instructions for setting up the local development environment, installing required tools, configuring environment variables, running tests, and executing the FastAPI application.

1. Prerequisites & Required Tools

Python 3.10+

  • Download and run the installer from python.org.
  • Important: Check the box for Add python.exe to PATH during installation.
  • Verify installation: python --version

Git

  • Download and install Git for Windows.
  • Verify installation: git --version

2. Repository & Virtual Environment Setup

Open PowerShell and navigate to the backend directory:

cd C:\Repository\adr-governance-studio\backend

# 1. Create Virtual Environment
python -m venv venv

# 2. Activate Virtual Environment
.\venv\Scripts\Activate.ps1

# 3. Install Required Dependencies
python -m pip install --upgrade pip
pip install fastapi uvicorn python-dotenv pytest pytest-cov
PowerShell Tip: If script execution is restricted, run Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process in your PowerShell session before activating the environment.

3. Configuration Files

Environment File (.env)

Create a .env file directly under backend/ with the following content:

GITHUB_WEBHOOK_SECRET=development_secret
ENVIRONMENT=development
PORT=8000

Governance Policy File (governance_policy.json)

Ensure governance_policy.json exists in the backend/ folder:

{
  "policy_version": "1.0",
  "rules": [
    {
      "id": "ADR-001",
      "name": "Mandatory Status Section",
      "required": true
    }
  ]
}

4. Testing & Pre-Flight Health Checks

The system enforces a 90% code coverage threshold before starting up.

# Run unit tests directly
python -m pytest -vv

# Run unit tests with code coverage report
python -m pytest --cov=main --cov-report=term-missing

5. Running the Application

Automated Launch (Recommended)

.\start-backend.ps1

Direct Server Launch

python -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
